Instalación y print()

Instala las herramientas y escribe tus primeras líneas. Sigue los pasos en el orden de la clase.

Paso 1 · El intérprete

El computador solo entiende ceros y unos. El intérprete de Python es el traductor: lee tu código línea por línea y lo ejecuta al momento. Sin él, un archivo .py es solo texto.

  1. Entra a python.org/downloads y descarga la versión que usa el curso, Python 3.13.13 (es la que se lleva bien con Manim, de la clase 9).
  2. Al instalar en Windows, marca la casilla Add python.exe to PATH. Sin ella, la consola no reconoce el comando python.
  3. Abre CMD o PowerShell y comprueba la instalación:
python --version

Paso 2 · El editor: VS Code

Visual Studio Code es un editor gratuito de Microsoft: el cuaderno donde escribes el código. Instálale la extensión Python de Microsoft, que agrega colores, detección de errores y el botón Run. Guarda siempre con Ctrl + S antes de ejecutar. Puedes ejecutar el archivo con Run o escribiendo python nombre_del_archivo.py en la terminal.

Paso 3 · print()

print() muestra información en pantalla. Si le pasas varios valores separados por comas, los une con un espacio, aunque mezcles texto y números. También puede calcular: suma, resta, multiplicación (*) y división (/).

# para guardar el progreso pulso los botones ctrl + s
print("Hola","Mundo","Python",5)
print(5+2)
print(5-2)
print(5*2)
print(5/2)

Ese espacio entre valores se puede cambiar con sep:

print("2026", "06", "19", sep="-")

Prueba tú: cambia los números y los textos. ¿Qué devuelve 5/2: 2 o 2.5?

Paso 4 · Operar con texto y números

Dentro de print, 5+5 se calcula, pero lo que va entre comillas es texto. Multiplicar un texto por un número lo repite.

print(5+5)
print("a"*5)

Prueba tú: prueba print("2+2") con comillas y sin ellas.

Paso 5 · Caracteres de escape y end

✦

La barra invertida \ (en Windows, Alt + 92) es el carácter de escape: le dice a Python que el siguiente símbolo es especial. \n salta de línea, \" y \' permiten escribir comillas dentro de un texto. Por defecto print termina con un salto de línea, y end="---" lo reemplaza. En tu ejercicio_3.py estas líneas están comentadas con # para probarlas una a una.

print("Bienvenidos","al","curso","de","python",end="---")
print("Mi nombre es","David Torrez")
print("Bienvenidos al \ncurso de python")
print("Bienvenidos al curso de \"python\"")
print("I\'m David Torrez")

Prueba tú: cambia el end por otro símbolo.

Paso 6 · Tu turno: la terminal

Escribe print("hola") o print(2+2) y pulsa Enter. Prueba también Print("hola") con mayúscula.

Practica

Una línea con tu nombre y tu edad
print("Mi nombre es", "Ana", "y tengo", 20, "años")

Resumen

  • El intérprete traduce y ejecuta tu código; VS Code es donde lo escribes.
  • print() acepta varios valores, calcula y se ajusta con sep y end.
  • La barra invertida permite saltos de línea y comillas dentro del texto.
  • Python distingue mayúsculas: Print no es print.
