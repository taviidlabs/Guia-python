Introducción

Antes de escribir código, conoce qué es Python, cómo piensa un computador y cómo vas a aprender en este viaje.

¿Qué es Python?

✦

Python es un lenguaje de programación creado por Guido van Rossum y lanzado en 1991. Se diseñó para que el código sea claro y se lea casi como instrucciones en inglés. Es gratuito, de código abierto y funciona igual en Windows, Mac y Linux.

Así se ve el clásico «Hola, mundo». En la próxima clase lo instalas y lo ejecutas tú.

print("Hola, mundo")

¿Qué es programar?

Un algoritmo es una lista ordenada de pasos para resolver un problema, como una receta de cocina. Un programa es un algoritmo escrito en un lenguaje que el computador puede ejecutar. Programar es, entonces, explicar con mucha precisión qué hacer y en qué orden.

El computador es obediente, pero no adivina: hace exactamente lo que le dices. Si falta un paso o está fuera de orden, el resultado sale mal.

Una persona entiendeEl computador necesita
«Ponle un poco de azúcar»«Agrega 1 cucharada de azúcar»
«Hazlo como la otra vez»Cada paso escrito de nuevo
«Si está frío, calientalo»Una condición exacta: «si la temperatura es menor que 40…»

De tu código a la pantalla

Cuando escribes un programa en Python pasa esto:

Escribes el código en un archivo .py
→
El intérprete lo lee línea por línea
→
Cada instrucción se ejecuta al momento
→
Ves el resultado o un mensaje de error

Los errores no son un fracaso: Python te dice el tipo de error y la línea donde ocurrió, y esa información es tu mejor ayuda para corregir.

Un poco de historia

1991Guido van Rossum publica la primera versión de Python. El nombre viene del grupo de humor Monty Python, no de la serpiente.
2000Llega Python 2.0, que añade nuevas herramientas al lenguaje.
2008Python 3.0 renueva el lenguaje y deja de ser compatible con la versión 2. Es la línea que se usa hoy, incluida la de este curso.
2020Python 2 deja de recibir soporte oficial.

La filosofía de Python

Python tiene un conjunto de principios de diseño conocido como el Zen de Python (PEP 20). Tres ideas para quedarte: lo simple es mejor que lo complejo, la legibilidad cuenta y conviene que haya una forma obvia de hacer las cosas. Por eso el código Python se ve ordenado, con sangrías que son parte de la sintaxis. Si te da curiosidad, busca PEP 20.

Lo que necesitas

  • Un computador con Windows, Mac o Linux.
  • Conexión a internet para instalar las herramientas y, más adelante, para trabajar con APIs.
  • Un editor de código: usaremos Visual Studio Code, y la clase 2 te guía en la instalación.
  • Curiosidad y constancia. No hace falta experiencia previa.

Cómo funciona esta guía

Cada clase sigue el mismo orden en que se enseña: pasos cortos, cada uno con el archivo de clase, su explicación y su resultado. Verás tres elementos:

  • Prueba tú: un pequeño experimento para cambiar el código y ver qué pasa.
  • Practica: ejercicios con la solución escondida. Intenta resolverlos antes de abrirla.
  • Estrellas escondidas ★: cada clase guarda algunas. El botón de la esquina inferior muestra las pistas. Tu rango sube a medida que avanzas, y se guarda en tu navegador.

Consejos para aprender

  1. Escribe el código tú mismo en lugar de copiar y pegar: así lo recuerdas.
  2. Cambia valores y observa qué ocurre. Equivocarse es parte de aprender.
  3. Lee los mensajes de error completos: indican el tipo y la línea.
  4. Practica un poco todos los días, aunque sean 15 minutos.
  5. Cuando algo no funcione, busca el mensaje de error en internet: alguien ya lo resolvió.

Resumen

  • Un algoritmo es una receta de pasos y un programa es esa receta escrita para el computador.
  • Python es un lenguaje claro, gratuito y multiplataforma, con usos en web, IA, datos, automatización y más.
