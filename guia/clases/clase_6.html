Mensajes, excepciones y tu primer dashboard

Los programas fallan. Aprende a avisar, preguntar y atrapar errores, y arma la primera pantalla del proyecto.

Paso 1 · Avisar con messagebox

Los cuadros de diálogo avisan al usuario sin usar la terminal. showinfo informa, showwarning advierte y showerror muestra un error. Cada uno recibe un título y un mensaje.

from tkinter import messagebox

def mostrar_info():
    messagebox.showinfo(
        "Informacion",
        "Este es un mensaje informativo"
    )

def mostrar_error():
    messagebox.showerror(
        "Error",
        "Ocurrio un error en el sistema"
    )

def mostrar_warning():
    messagebox.showwarning(
        "Advertencia",
        "Ten cuidado con esta accion"
    )

Prueba tú: cambia los mensajes y vuelve a abrirlos.

Paso 2 · Preguntar y reaccionar

askyesno, askokcancel y askretrycancel hacen una pregunta y devuelven True o False. Con un if se decide qué hacer según la respuesta. Pulsa cada diálogo y mira qué devuelve Python:

def preguntar_yesno():

    respuesta = messagebox.askyesno(
        "Pregunta",
        "¿Deseas continuar?"
    )

    if respuesta:
        resultado.config(text="El usuario presiono SI")
    else:
        resultado.config(text="El usuario presiono NO")

Prueba tú: abre los seis diálogos de arriba.

Paso 3 · try y except

Si el usuario escribe letras o un cero, el programa se rompe. try intenta el código y, si falla, Python salta al except que coincide con el error: ValueError si no es un número, ZeroDivisionError al dividir entre cero y Exception as e para cualquier otro error, siempre al final. Rompe el programa tú mismo:

calculadora.py
Pulsa Ejecutar.
def probar_try():

    try:
        numero = int(entry_numero.get())

        resultado_div = 10 / numero

        messagebox.showinfo(
            "Resultado",
            f"Resultado: {resultado_div}"
        )

    except ValueError:

        messagebox.showerror(
            "Error de Valor",
            "Debes ingresar solo numeros"
        )

    except ZeroDivisionError:

        messagebox.showerror(
            "Error Matematico",
            "No se puede dividir entre cero"
        )

    except Exception as e:

        messagebox.showerror(
            "Error General",
            str(e)
        )

Paso 4 · Tu primer dashboard
proyecto.py es la primera pantalla del analizador de minimarket. Un Frame es un contenedor que agrupa widgets (encabezado, botones y tabla). pack(fill=tk.X) lo estira a lo ancho y fill=tk.BOTH, expand=True lo deja crecer con la ventana. Los tres botones se ordenan con grid(row=0, column=...).
La tabla es un ttk.Treeview: columns define las columnas, heading los títulos e insert agrega una fila. Antes de llenarla, get_children() y delete borran las filas anteriores. En f"Bs {item[2]:.2f}", :.2f muestra el precio con 2 decimales. Los botones de Excel y gráficos aún solo muestran un aviso: se completan en las próximas clases.
import tkinter as tk
from tkinter import ttk
from tkinter import messagebox

ventana=tk.Tk()
ventana.title("Dashboard Minimarket")
ventana.geometry("900x650")
ventana.configure(bg="#f3f4f6")

#-------------Funciones-----------

    for item in datos_prueba:
        tabla.insert("",tk.END,values=(item[0],item[1],f"Bs {item[2]:.2f}"))

def exportar_excel():
    messagebox.showinfo("Proximamente","Aqui se hara el excel")

#----------Encabezado---------------

frame_header=tk.Frame(ventana,bg="#ffffff")

Practica
Una función que no se rompe al dividir
def dividir(a, b):
    try:
        return a / b
    except ZeroDivisionError:
        return "No se puede dividir entre cero"

print(dividir(10, 2))
print(dividir(10, 0))


Resumen
  • showinfo, showwarning y showerror avisan; las ask... preguntan y devuelven True o False.
  • try intenta y except atrapa el error sin cerrar el programa.
  • Los except específicos van primero y Exception al final.
  • Frame agrupa, grid ordena y Treeview muestra tablas.
