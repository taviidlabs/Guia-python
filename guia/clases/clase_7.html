Datos de internet: APIs, JSON y Excel

Tus programas salen a internet: piden datos a otros servicios, leen JSON y Excel y hasta conversan con una IA.

Paso 1 · Tu primera API

Una API es una puerta para pedirle datos a otro programa. Aquí le pides a PokéAPI los datos de un Pokémon. requests no viene con Python: se instala una vez con pip install requests. requests.get(url) hace la petición, status_code == 200 significa que todo salió bien y .json() convierte la respuesta en un diccionario.

Elige una clave y mira cómo se lee:

Elige una clave.

import requests

response=requests.get("https://pokeapi.co/api/v2/pokemon/charmander")

if response.status_code==200:
    datos=response.json()
    
    print(f"Nombre: {datos['name']}")
    print(f"Peso: {datos['weight']}")
    print(f"Altura: {datos['height']}")
else:
    print(f"Error: {response.status_code}")

Paso 2 · Wikipedia y los headers

Algunas APIs piden que te identifiques. Con headers mandas información extra en la petición: aquí un User-Agent que dice quién eres. Wikipedia lo pide, y sin él puede rechazar la petición. Cada ejecución devuelve un artículo distinto.

import requests

headers = {
    "User-Agent": "ClaseDePython/1.0 (estudiante@ejemplo.com)"
}

response = requests.get(
    "https://es.wikipedia.org/api/rest_v1/page/random/summary",
    headers=headers
)

if response.status_code == 200:
    datos = response.json()
    print(f"📖 {datos['title']}")
    print(f"\n{datos['extract']}")
else:
    print(f"Error: {response.status_code}")

Paso 3 · El clima: parámetros y errores

Aquí la petición lleva parámetros: params es un diccionario que requests convierte en ?latitude=...&longitude=... al final de la URL. timeout=10 evita esperar para siempre y raise_for_status() lanza un error si la respuesta no fue exitosa. Los tres except distinguen sin internet, demora y error del servidor. Open-Meteo es gratuita y no pide API key. Los diccionarios tienen .get(clave, valor_por_defecto): si la clave no existe no da error. Abajo, solo el inicio de lo que imprime.

def obtener_clima(ciudad_info: dict) -> dict | None:
    # Hace una petición GET a la API de Open-Meteo.
    # Retorna un diccionario con los datos del clima o None si falla.
    url = "https://api.open-meteo.com/v1/forecast"

    # Parámetros de la petición (van en la URL como ?param=valor)
    parametros = {
        "latitude":        ciudad_info["lat"],
        "longitude":       ciudad_info["lon"],
        "current":         "temperature_2m,relative_humidity_2m,apparent_temperature,"
                           "weather_code,wind_speed_10m,precipitation",
        "daily":           "temperature_2m_max,temperature_2m_min",
        "timezone":        "auto",
        "forecast_days":   3,
    }

    print(f"\n  Enviando petición GET a: {url}")
    print(f"  Parámetros: lat={ciudad_info['lat']}, lon={ciudad_info['lon']}")

    try:
        # ── La petición HTTP GET ─────────────────────────────────────
        respuesta = requests.get(url, params=parametros, timeout=10)

        print(f"  Código de respuesta HTTP: {respuesta.status_code}")

        # Verificar que la petición fue exitosa (código 200)
        respuesta.raise_for_status()

        # Convertir la respuesta JSON a diccionario Python
        datos_json = respuesta.json()
        ...  # se arma el resultado con datos_json.get(...)

    except requests.exceptions.ConnectionError:
        print("  Error: No hay conexión a internet.")
        return None
    except requests.exceptions.Timeout:
        print("  Error: La API tardó demasiado en responder.")
        return None
    except requests.exceptions.HTTPError as e:
        print(f"  Error HTTP: {e}")
        return None

El archivo termina con un punto de entrada. El código dentro de este if solo corre cuando ejecutas este archivo directamente, no cuando otro archivo lo importa:

# ── Punto de entrada ─────────────────────────────────────────────────
if __name__ == "__main__":
    menu()

Paso 4 · La API dentro del dashboard

Es el mismo dashboard de la clase 6, pero ahora el botón descarga el catálogo de internet. La función pide los datos, limpia la tabla y agrega una fila por producto. Si algo falla, el except muestra un aviso en vez de cerrar el programa.

def descargar_datos():
    try:
        url = "https://fakestoreapi.com/products"
        respuesta = requests.get(url)
        datos_json = respuesta.json()
        
        for fila in tabla.get_children():
            tabla.delete(fila)
            
        for item in datos_json:
            id_prod = item["id"]
            nombre = item["title"]
            precio = item["price"]
            tabla.insert("", tk.END, values=(id_prod, nombre, f"${precio:.2f}"))
            
        messagebox.showinfo("Éxito", "¡Catálogo descargado de internet!")
    except Exception as e:
        messagebox.showerror("Error de Conexion","No se pudo conectar a la API")

Paso 5 · Datos desde un archivo JSON

No siempre hay internet. Los mismos datos pueden vivir en un archivo JSON, que se parece a una lista de diccionarios de Python:

[
    {
        "id": 1,
        "title": "Arroz 1kg",
        "price": 8.5
    },
    {
        "id": 2,
        "title": "Azúcar 1kg",
        "price": 7.8
    }
]

os.path arma la ruta del JSON junto a tu programa, sin importar desde dónde lo ejecutes. La rama frozen es para cuando el programa se convierte en .exe, algo que harás en la clase 9. with open(...) abre y cierra el archivo solo, y json.load lo convierte en datos de Python. El módulo json ya viene con Python: no necesita pip.

if getattr(sys, 'frozen', False):
    BASE_DIR =os.path.dirname(sys.executable)
else:
    BASE_DIR = os.path.dirname(os.path.abspath(__file__))
    
RUTA_JSON= os.path.join(BASE_DIR, "productos_minimarket.json")
#--------------funciones---------------------------------------------------
def descargar_datos():
    try:
        with open(RUTA_JSON, "r", encoding="utf-8") as archivo:
            datos_json=json.load(archivo)
        
        for fila in tabla.get_children():
            tabla.delete(fila)
        
        for item in datos_json:
            tabla.insert("", tk.END, values=(item["id"], item["title"], f"Bs{item['price']:.2f}"))
        
        messagebox.showinfo("EXITO", "Catalogo cargado")
    except Exception as e:
        messagebox.showerror("ERROR", str(e))

Paso 6 · Extra: datos desde Excel

Un tercer origen de datos es un archivo de Excel. Para leerlo se usa pandas, que junto con openpyxl se instala con pip install pandas openpyxl. pd.read_excel devuelve una tabla y iterrows() la recorre fila por fila. Como el precio viene como «Bs8.5», se limpia el texto antes de pasarlo a número. Es un extra: estas librerías se vuelven a usar en la clase 8.

def descargar_datos():
    try:

        df = pd.read_excel("Reporte_Mercado.xlsx")

        for fila in tabla.get_children():
            tabla.delete(fila)

        for index, row in df.iterrows():

            id_prod = row["ID"]
            nombre = row["Producto"]

            # Convierte el precio a numero
            precio = float(str(row["Precio"]).replace("Bs", "").strip())

            tabla.insert(
                "",
                tk.END,
                values=(id_prod, nombre, f"Bs{precio:.2f}")
            )

        messagebox.showinfo(
            "Éxito",
            "Datos cargados desde Excel"
        )

    except Exception as e:
        messagebox.showerror(
            "Error",
            str(e)
        )

Paso 7 · Una IA en tu computadora

Con una API también puedes conversar con una IA. Ollama corre un modelo en tu propia máquina y abre un servidor local, sin cuenta, sin internet y sin API key. Ahora la petición es requests.post, que envía datos (aquí el texto que le pides). El resto de api1.py y api2.py arma una lista de compras con casillas; la petición corre en un hilo (threading) para que la ventana no se congele mientras la IA responde. En api2.py mejoraste el texto de la petición (el prompt) para platos de Bolivia.

import requests

OLLAMA_URL = "http://localhost:11434/api/generate"
MODELO = "llama3.2"

respuesta = requests.post(
    OLLAMA_URL,
    json={"model": MODELO, "prompt": prompt, "stream": False},

respuesta.raise_for_status()
texto = respuesta.json().get("response", "[]").strip()

Paso 8 · La API key: Groq en la nube

✦

Una API key es como una contraseña que identifica tu cuenta: con ella el servicio sabe quién pide y puede limitar el uso. Groq corre el modelo en internet, y por eso pide la clave en un header Authorization. Cambia cuatro cosas respecto a Ollama:

Ollama (local)Groq (nube)
URL localhostURL en internet
Sin claveHeader Authorization con la clave
"prompt" con texto plano"messages", formato de chat
.json()["response"].json()["choices"][0]["message"]["content"]

Si la clave es inválida, raise_for_status() lanza un HTTPError. Los nombres de modelo cambian con el tiempo: revisa el vigente en la consola de Groq. api_groq.py hace lo mismo con tarjetas, íconos y animación de carga.

import requests

GROQ_URL = "https://api.groq.com/openai/v1/chat/completions"
GROQ_API_KEY = "TU_API_KEY_AQUI"   # tu clave personal
MODELO = "openai/gpt-oss-120b"

respuesta = requests.post(
    GROQ_URL,
    headers={
        "Authorization": f"Bearer {GROQ_API_KEY}",
        "Content-Type": "application/json",
    },
    json={
        "model": MODELO,
        "messages": [{"role": "user", "content": prompt}],
    },
    timeout=60,
)
respuesta.raise_for_status()
texto = respuesta.json()["choices"][0]["message"]["content"].strip()

Ampliación: cuida tu clave

Una clave nunca debe quedar escrita en código que compartes o subes a internet: si se filtra, otros pueden usarla a tu nombre. Si pasa, revócala en la consola y crea otra. Una forma más segura es guardarla fuera del código, en una variable de entorno:

import os

GROQ_API_KEY = os.environ["GROQ_API_KEY"]   # la clave vive fuera del código

Resumen

  • requests.get pide datos y .json() los convierte en un diccionario.
  • headers, params y timeout ajustan la petición; raise_for_status() detecta errores.
  • Los datos pueden venir de una API, un JSON o un Excel, y la tabla se llena igual.
  • requests.post envía datos; una API key identifica tu cuenta y no se comparte.
