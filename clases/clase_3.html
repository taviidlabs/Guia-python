Variables y datos

Aprende a guardar información en variables, a convertir sus tipos y a organizarla en listas, tuplas y diccionarios.

Paso 1 · Variables: cajas con nombre

Una variable es una caja con nombre donde guardas un valor. caja1 = 2 guarda el 2 en la caja llamada caja1. El signo = asigna, no compara. Los nombres usan letras, números y guion bajo, sin espacios y sin empezar con número. Si guardas otro valor con el mismo nombre, la caja cambia de contenido.

caja1 = 2
caja2 = 3
caja_grande = caja1 + caja2
print(caja_grande)

Paso 2 · Tipos de dato y conversión

Cada valor tiene un tipo: int (enteros), float (decimales), str (texto) y bool (verdadero o falso). input() siempre devuelve texto, por eso se convierte: int(...), float(...), str(...). Fíjate que int(n1/n2) descarta los decimales: 3.5 pasa a 3.

# numeros enteros ------->int
# numeros decimales ------> float
# cadenas de texto ------->str
# datos boolenas ---------> bool

n1=int(input("ponga un numero ---> "))
n2=int(input("ponga otro numero ---> "))
s=str(n1+n2)
r=float(n1-n2)
m=float(n1*n2)
d=int(n1/n2)
print(s)
print(r)
print(m)
print(d)

Paso 3 · input y f-strings

Una f-string lleva una f antes de las comillas y deja meter variables entre llaves: {n1}. Así el mensaje queda armado sin pegar textos a mano.

n1=int(input("ponga un numero ---> "))
n2=int(input("ponga otro numero ---> "))
s=n1+n2
r=n1-n2
m=n1*n2
d=n1/n2
print(f"la suma de {n1} + {n2} es:",s)
print(f"la resta de {n1} - {n2} es:",r)
print(f"la multiplicacion de {n1} * {n2} es:",m)
print(f"la division de {n1} / {n2} es:",d)

Prueba tú: cambia los textos de los mensajes.

Paso 4 · Fórmulas: el área del círculo

Aquí el programa pide un radio decimal con float(input()). PI va en mayúsculas por convención: es un valor que no cambia. ** es la potencia, así que radio**2 es el radio al cuadrado.

#Area del Circulo
radio=float(input("ponga el dato del radio: "))
PI=3.1416
area=PI*(radio**2)
print("El area del circulo es:",area)

Prueba tú: prueba con radio 10 y observa los decimales largos: la computadora guarda los decimales de forma aproximada, y es normal.

Paso 5 · Listas

Una lista guarda varios valores entre corchetes. Cada uno tiene una posición que empieza en 0, y se puede modificar.

print("Listas")
#           0         1      2
frutas=["Manzana","Banana","Uva"]
frutas[1]="Naranja"
print(frutas)

Prueba tú: cambia la posición 0 y vuelve a imprimir.

Paso 6 · Tuplas

Una tupla se parece a una lista pero va entre paréntesis y no se puede modificar. Si intentas numeros[1] = 100, Python da un error.

print("Tuplas")
#        0 1  2 3 4
numeros=(2,10,5,8,1)
#  numeros[1]=100 ---------> no se puede modificar
print(numeros[2])

Paso 7 · Diccionarios

✦

Un diccionario guarda pares clave: valor. En vez de una posición, buscas por el nombre de la clave.

persona={
    "Nombre":"David",
    "Apellido":"Torrez",
    "Edad":28,
    "lenguaje_de_programacion":"Python"
}
print(persona["lenguaje_de_programacion"])

Prueba tú: imprime el nombre y la edad de la persona.

Practica

Promedio de dos números
a = float(input("a: "))
b = float(input("b: "))
print("El promedio es:", (a + b) / 2)

Resumen

  • Una variable es una caja con nombre; = asigna.
  • Los tipos básicos son int, float, str y bool, y se convierten con sus funciones.
  • input() devuelve texto; las f-strings arman mensajes con variables.
  • Las listas se modifican, las tuplas no, y los diccionarios guardan pares clave-valor.
