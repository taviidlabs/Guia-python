Decisiones, bucles y funciones

Aquí el programa empieza a pensar: decide, repite y se organiza en funciones. Sigue los pasos en el mismo orden de la clase.

Paso 1 · Decidir con if y else

Un programa a veces tiene que decidir. if hace una pregunta: si la respuesta es verdadera ejecuta su bloque, y si no, ejecuta el de else. Para preguntar se usan los operadores de comparación: == igual, != diferente, >, <, >= y <=.

Ojo: = guarda un valor en una variable (asignación) y == compara dos valores. Son cosas distintas. Los dos puntos y la sangría de 4 espacios marcan qué líneas pertenecen a cada bloque. int() convierte en número lo que se escribe con input, como vimos en la clase 3.

# = ---------> es asignacion
# 2==2 --------> comparacion
# != ----------> diferente
# >, <, >=, <=

print("Condicionales")

#if condicion:
#    instrucciones
#else:
#    instrucciones

edad=int(input("introducir edad: "))

if edad>=18:
    print("Mayor de edad")
else:
    print("menor de edad")

Prueba tú: cambia la edad a 18 y luego a 17, y mira qué pasa justo en el límite.

Paso 2 · Ejercicio: la contraseña

El mismo if/else funciona con texto. Aquí se compara lo que escribe el usuario con la clave guardada: intento == clave. Python distingue mayúsculas de minúsculas, así que Python y python son textos distintos.

clave="python"
intento=input("ingrese la contraseña: ")

if intento==clave:
    print("Acceso concedido")
else:
    print("Clave incorrecta")

Prueba tú: cambia la clave guardada y comprueba que la comparación sigue funcionando.

Paso 3 · Anidación: un if dentro de otro

Cuando hay más de dos caminos, puedes poner un if dentro del else de otro. Eso se llama anidación. Python entra al if de afuera y, si no se cumple, baja al else y revisa el siguiente.

Con nota 55: no es mayor que 90, no es mayor que 60 y sí es mayor que 50, así que imprime «Refuerzo». Fíjate en el borde: con exactamente 90, nota > 90 es falso, y el programa imprime «Aprobado». Y cada nivel empuja el código más a la derecha.

nota=int(input("Introducir nota: "))

if nota>90:
    print("Excelencia")
else:
    if nota>60:
        print("Aprobado")
    else:
        if nota>50:
            print("Refuerzo")
        else:
            print("Reprobado")

Prueba tú: escribe 90 y 91, y comprueba la diferencia.

Paso 4 · elif: lo mismo, más ordenado

✦

elif (else + if) hace lo mismo que la anidación sin hundir el código: se revisan las condiciones de arriba abajo y se ejecuta solo el primer bloque verdadero. El resultado es idéntico al del paso anterior, pero se lee mucho mejor.

nota=int(input("Introducir nota: "))

if nota>90:
    print("Excelencia")
elif nota>60:
    print("Aprobado")
elif nota>50:
    print("Refuerzo")
else:
    print("Reprobado")

Prueba tú: ¿qué tendrías que cambiar para que el 90 cuente como «Excelencia»?

Paso 5 · for y range

Un bucle repite instrucciones. for recorre una secuencia, y range(inicio, fin, salto) fabrica los números: empieza en 2, avanza de 2 en 2 y se detiene antes de llegar a 20, porque el valor final nunca se incluye.

#for variable in range(inicio,fin,saltos):
#    instrucciones

for i in range(2,20,2):
    print(i)

Prueba tú: prueba range(1, 6) y range(10, 0, -2).

Paso 6 · for sobre un texto

El for también recorre un texto letra por letra. contador empieza en 0 y sube 1 cada vez que la letra es «a». Al terminar, print muestra el total. La f antes de las comillas (f-string) permite meter variables entre llaves.

palabra="aaaalaaalaa"
contador=0
for letra in palabra:
    if letra=="a":
        contador=contador+1
print(f"La palabra {palabra} tiene {contador} letras 'a'")

Prueba tú: cambia la palabra y comprueba que el conteo coincide con el tuyo.

Paso 7 · while: repetir mientras se cumpla algo

while repite mientras su condición sea verdadera. Aquí i empieza en 1 y, mientras i <= 5, imprime y suma 1 (i += 1 equivale a i = i + 1). Si esa línea faltara, la condición nunca cambiaría y el bucle no terminaría.

#while condicion:
#    instrucciones

i=1
while i<=5:
    print(i)
    i+=1

Prueba tú: cambia el 5 por otro número.

Paso 8 · while con la respuesta del usuario

Ahora el bucle depende de lo que responda el usuario: se repite mientras respuesta == "si". Dentro del bucle se vuelve a preguntar. Cuando escribe otra cosa, la condición es falsa, sale del bucle y se ejecuta la última línea.

respuesta="si"
while respuesta=="si":
    print("El programa sigue...")
    respuesta=input("Quieres otra vuelta? (si/no): ")
print("El programa se cerro")

Prueba tú: responde «SI» en mayúsculas y observa qué pasa.

Paso 9 · Funciones: bloques con nombre

Una función es un bloque de código con nombre que puedes reutilizar. Se define con def nombre(parametro): y se ejecuta al llamarla. El parámetro toma el valor que le pases en cada llamada, por eso la misma función saluda a tres personas distintas.

#def nombre(parametros):
#    instrucciones

def saludar(nombre):
    print("Hola, bienvenida/o a la clase de python",nombre)



saludar("Naim")
saludar("Andrea")
saludar("Edwin")

Prueba tú: agrega una cuarta llamada con tu nombre.

Paso 10 · return: devolver un valor

El archivo trae dos versiones. La primera, entre ''' para que no se ejecute, imprime dentro de la función. La segunda usa return: la función entrega el valor y quien la llamó lo guarda en una variable. print solo muestra en pantalla; return entrega el valor para que lo uses después.

'''
def sumar (a,b):
    print(a+b)

sumar(2,3)
sumar(6,4)
'''
def sumar (a,b):
    return a+b

resultado=sumar(2,3)
print(resultado)

Prueba tú: guarda el resultado de dos llamadas y súmalos.

Paso 11 · Devolver varios valores

Una función puede devolver varios valores separados por comas, y al llamarla se reciben en varias variables a la vez: m, n, p = analizar(datos). max, min, sum y len ya vienen con Python.

def analizar(lista):
    mayor=max(lista)
    menor=min(lista)
    promedio=sum(lista)/len(lista)
    
    return mayor,menor,promedio


datos=[5,10,15]
m,n,p=analizar(datos)

print("Mayor", m)
print("menor", n)
print("Promedio",p)

Prueba tú: cambia la lista y comprueba mayor, menor y promedio a mano.

Resumen

  • if / else decide entre dos caminos y elif permite más, revisando de arriba abajo.
  • = asigna y == compara.
  • for recorre una secuencia y range genera números sin incluir el final.
  • while repite mientras la condición sea verdadera.
  • def define una función y return entrega un valor, o varios.
