Empaquetado y Manim

Convierte tu dashboard en un programa que se abre con doble clic y cierra el curso con una animación hecha con código.

Paso 1 · Por qué empaquetar

Para ejecutar tu dashboard hace falta tener Python y sus librerías instaladas. Empaquetar convierte el proyecto en un archivo .exe que se abre con doble clic, incluso en un computador sin Python. Usaremos PyInstaller.

¿Recuerdas sys.frozen y sys.executable de la clase 7? Ahora cobran sentido: el programa los usa para saber si corre como script o como .exe, y así buscar el JSON junto al ejecutable.

Paso 2 · Instalar PyInstaller y las dependencias

Primero se instala la herramienta y se comprueba. Después, las librerías que usa tu proyecto; openpyxl hace falta para que pandas pueda generar archivos .xlsx.

pip install pyinstaller
pyinstaller --version
pip install pandas matplotlib openpyxl

Paso 3 · Ordenar los archivos y conseguir el ícono

Tu carpeta debe verse así antes de empaquetar. El ícono tiene que ser un archivo .ico, y estar en la misma carpeta que el .py; un PNG o JPG no sirve.

📁 mi_proyecto/
  ├── dashboard.py
  ├── productos_minimarket.json
  └── icono.ico

Puedes descargar un ícono en icon-icons.com, un sitio con miles de íconos gratuitos en colecciones temáticas, donde eliges el tamaño y el formato antes de descargar. Elige el formato ICO y revisa la licencia de cada ícono antes de usarlo. Si solo lo tienes en PNG, conviértelo en convertico.com.

Paso 4 · Ejecutar PyInstaller

Marca y desmarca las opciones para armar el comando y mira qué cambia en el resultado.

    

    Paso 5 · Encontrar el .exe
    PyInstaller crea carpetas por su cuenta (pulsa «Ejecutar» arriba para verlas): build guarda archivos temporales que puedes ignorar, dist contiene tu .exe y dashboard.spec es la configuración generada.
    

    Paso 6 · Copiar el JSON junto al .exe
    El .exe no lleva dentro el JSON ni el ícono. Copia el JSON a la carpeta que vas a entregar, junto al .exe (pulsa el segundo botón de arriba). Sin él, la aplicación no podrá cargar ni guardar datos.

    Paso 7 · ¿Qué es Manim?
    Manim es una librería de Python para crear animaciones con código. La creó Grant Sanderson, de 3Blue1Brown, para sus videos de matemáticas. Hoy se usa la versión de la comunidad, Manim Community, más estable y mejor documentada. Se instala con pip install manim. Y si solo quieres probar, try.manim.community funciona en el navegador, sin instalar nada.
    

    Paso 8 · Antes de animar: ¿qué es una clase?
    Hasta ahora usaste funciones. Una clase es un molde para crear objetos que reúnen datos y comportamientos. Manim se construye con clases, así que aquí solo necesitas reconocer cuatro piezas:
    class MiPrimeraAnimacion(Scene)Crea tu clase y hereda todo lo de Scene, como play() y wait().
    def construct(self)El método que Manim ejecuta para dibujar la escena.
    self«Esta misma escena».
    métodoUna función que vive dentro de una clase.
    

    Paso 9 · Tu primera animación
    Primero se crean los objetos: un texto, un cuadrado azul y un círculo rojo. Luego se colocan (to_edge(UP) arriba, shift(LEFT*2) a la izquierda, shift(RIGHT*2) a la derecha). Después se animan con self.play(...): Write escribe el texto, Create dibuja cada figura y Transform convierte el cuadrado en círculo. self.wait(n) pausa n segundos. En un archivo .py hace falta from manim import * al inicio. Mira cómo se ve:
    Felicidades por terminar el curso
    Es una réplica en CSS; el video real lo genera Manim.
    from manim import *
#https://hub.gesis.mybinder.org/user/manimcommunity-jupyter_examples-vjdtopcp/notebooks/First%20Steps%20with%20Manim.ipynb

class MiPrimeraAnimacion(Scene):
    def construct(self):
        texto=Text("Felicidades por terminar el curso",font_size=36)
        cuadrado=Square(color=BLUE, fill_opacity=0.5)
        circulo=Circle(color=RED,fill_opacity=0.8)
        
        texto.to_edge(UP)
        cuadrado.shift(LEFT*2)
        circulo.shift(RIGHT*2)
        
        self.play(Write(texto))
        
        self.play(Create(cuadrado))
        self.wait(10)
        
        self.play(Create(circulo))
        self.wait(5)
        
        self.play(Transform(cuadrado,circulo))
        self.wait(15)
# manim -pql mi_animacion.py MiPrimeraAnimacion -----> vs code
# %%manim -qm -v WARNING MiPrimeraAnimacion -------> tryManim
    Prueba tú: cambia los colores o los segundos de wait.
    

    Paso 10 · Ejecutarla
    En la terminal de VS Code, dentro de la carpeta del archivo, escribe el primer comando; -p abre el video al terminar y -ql usa calidad baja, que renderiza más rápido. En try.manim.community se usa la línea mágica del segundo. Manim guarda el video en una carpeta media.
    manim -pql mi_animacion.py MiPrimeraAnimacion
    %%manim -qm -v WARNING MiPrimeraAnimacion

    Resumen
    • pyinstaller --onefile --windowed --icon=icono.ico archivo.py convierte tu proyecto en un .exe.
    • El .exe aparece en dist, y el JSON debe copiarse junto a él.
    • El ícono debe ser .ico.
    • En Manim, una clase hereda de Scene y todo se escribe en construct.
